# 🐾 User Stories

## EP1 - Cadastro e Autenticação

| User Story | Descrição |
|---|---|
| US01 | Como **visitante**, quero criar uma conta com nome, e-mail, telefone e senha para começar a usar o sistema. |
| US02 | Como **tutor**, quero fazer login e permanecer autenticado para não precisar logar toda vez que abrir o app. |
| US03 | Como **tutor**, quero editar meus dados cadastrais para manter minhas informações atualizadas. |

## EP2 - Cadastro e Gerenciamento de Pets

| User Story | Descrição |
|---|---|
| US04 | Como **tutor**, quero cadastrar meu pet com nome, espécie, raça, data de nascimento e foto para identificá-lo no sistema. |
| US05 | Como **tutor**, quero editar as informações do meu pet para corrigir ou atualizar dados. |
| US06 | Como **tutor**, quero excluir o cadastro de um pet caso não precise mais dele no sistema. |
| US07 | Como **tutor**, quero ver a lista de todos os meus pets cadastrados em um só lugar. |

## EP3 - Medalha e Escaneamento

| User Story | Descrição |
|---|---|
| US08 | Como **tutor**, quero gerar uma medalha para o meu pet para colocar na coleira dele. |
| US09 | Como **pessoa que encontrou o pet**, quero escanear a medalha e ver os dados do animal e do tutor sem precisar instalar nenhum aplicativo. |
| US10 | Como **tutor**, quero que o local e horário de cada leitura da medalha sejam registrados para saber onde meu pet foi visto. |
| US11 | Como **tutor**, quero poder desativar a medalha do meu pet caso ela seja perdida ou substituída. |

## EP4 - Contatos de Emergência e Pet Perdido

| User Story | Descrição |
|---|---|
| US12 | Como **tutor**, quero cadastrar contatos de emergência para o meu pet, para que quem o encontre saiba com quem falar. |
| US13 | Como **tutor**, quero definir a prioridade dos contatos de emergência, para que o mais importante apareça primeiro. |
| US14 | Como **pessoa que encontrou o pet**, quero visualizar rapidamente um contato para avisar o tutor. |

## EP5 - Assinaturas e Planos

| User Story | Descrição |
|---|---|
| US15 | Como **tutor**, quero visualizar os planos disponíveis (Básico, Premium, Família) para escolher o que melhor atende às minhas necessidades. |
| US16 | Como **tutor**, quero assinar um plano para desbloquear os recursos correspondentes. |
| US17 | Como **tutor**, quero visualizar o status da minha assinatura (ativa, cancelada, expirada) para saber se preciso renovar. |
